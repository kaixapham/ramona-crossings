# Ramona · Evening Crossings

Bản build tĩnh của một website demo cho chuyến tàu hơi nước Ramona (hư cấu). Trang mở đầu bằng cảnh 3D Three.js, giữa là phần editorial trên nền giấy (typography theo tinh thần aupalevodka.com), lộ trình 3D là hải đồ trên bàn với chiếc Ramona nhỏ chạy qua 5 chặng, rồi quay lại cảnh biển qua ô cửa tròn. Cuộn mượt bằng Lenis. Phím H hoặc nút ⚙ mở bảng chỉnh cảnh, nút i hiện ghi công.

Xem tại: https://kaixapham.github.io/ramona-crossings/

- Chuyến đi, lịch chạy và giá vé đều là hư cấu.

Model được đóng gói dạng base64 (`models/*.glb.txt`).
